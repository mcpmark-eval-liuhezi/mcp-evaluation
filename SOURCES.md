# Sources

Every source URL used in BRIEFING.md, with a one-line note on what it backed.

1. **https://github.com/modelcontextprotocol/modelcontextprotocol** — Official specification and documentation repo; README confirms the spec, protocol schema (TypeScript-defined, JSON Schema available), authors (David Soria Parra, Justin Spahr-Summers), MIT license, and SEP/working-group contribution process.
2. **https://modelcontextprotocol.io** — Official MCP documentation site (Mintlify-built per spec repo README); architecture overview, transport layer, and specification at /specification/latest.
3. **https://github.com/modelcontextprotocol/python-sdk** — Official Python SDK README; defines MCP as "a web API, but designed for LLM interactions," lists the tools/resources/prompts primitives and stdio, Streamable HTTP, and SSE transports, and notes Python 3.11+ requirements and docs at py.sdk.modelcontextprotocol.io.
4. **https://py.sdk.modelcontextprotocol.io/** — Python SDK documentation site; get-started guide, "What's new in v2," API reference, and migration guide.
5. **https://github.com/modelcontextprotocol/servers** — Reference servers repo (~92k stars); documents host/client/server model, the stdio vs Streamable HTTP transport table, the MCP Inspector, the MCP Registry, the ten official SDKs, and archived servers.
6. **https://github.com/modelcontextprotocol** — GitHub organization hosting the spec, all ten official SDKs, reference servers, and the MCP Registry.
7. **https://github.com/wong2/awesome-mcp-servers** — Curated list of MCP servers (~4.4k stars); evidence of broad community server ecosystem and adoption breadth.
8. **https://github.com/modelcontextprotocol/inspector** — MCP Inspector debugging tool referenced by the servers README for browser-based testing of stdio and Streamable HTTP servers.
9. **https://registry.modelcontextprotocol.io** — Official MCP Registry for browsing published servers referenced by the servers README.
10. **https://github.com/modelcontextprotocol/modelcontextprotocol/releases** — Release tags for dated spec revisions: 2024-11-05, 2025-03-26, 2025-06-18, 2025-11-25, and current stable 2026-07-28; confirms revision cadence and stability.
11. **https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/.github/workflows** — Active CI workflows (docs-build, docs-validate, markdown-format, cut-release, deploy-blog); evidence of spec governance maturity.
12. **https://github.com/modelcontextprotocol/typescript-sdk** — One of ten official MCP SDKs (TypeScript); part of the multi-language adoption signal.
