# Sources

Every source URL used in BRIEFING.md, with a one-line note on what it backed.

1. https://github.com/modelcontextprotocol/modelcontextprotocol — Official spec & documentation repo: defines MCP as containing "the MCP specification, MCP protocol schema, and official MCP documentation"; notes the schema is defined in TypeScript and available as JSON Schema; lists authors (David Soria Parra, Justin Spahr-Summers), MIT license, and SEP/working-group contribution process.

2. https://github.com/modelcontextprotocol/servers — Reference servers repo (~92k stars): documents host/client/server architecture, the two standard transports (stdio and Streamable HTTP) with a comparison table, the ten official SDKs, and the MCP Inspector testing tool.

3. https://github.com/modelcontextprotocol/python-sdk — Official Python SDK (~24.8k stars, ~4.1k forks): evidence of broad language ecosystem adoption for building MCP servers and clients.

4. https://github.com/modelcontextprotocol/inspector — Deterministic testing tools for MCP servers: evidence of official debugging/testing tooling in the ecosystem.

5. https://modelcontextprotocol.io — Official documentation website (Mintlify-built): primary source for the architecture overview, host/client/server model, and transport layer.

6. https://modelcontextprotocol.io/specification/2026-07-28 — The current stable specification revision (release `2026-07-28`): backs the claim that spec maturity has reached a stable, versioned revision with a published changelog.

7. https://github.com/modelcontextprotocol/modelcontextprotocol/releases/tag/2026-07-28 — Release announcement confirming `2026-07-28` is the stable release of that spec revision.

8. https://registry.modelcontextprotocol.io/ — Official MCP Registry: backs the claim that a central catalog of published servers exists for the ecosystem.

9. https://github.com/mcpmark-eval-liuhezi/mcp-evaluation — This evaluation tracking repository (existing in the user's org): contextual evidence of active internal MCP adoption evaluation effort.
